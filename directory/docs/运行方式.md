# 商城管理系统运行方式


## 一、项目说明


本项目为电商平台商家后台系统。


采用技术：

- 前端：Vue 3 + Vite + Element Plus
- 后端：FastAPI + SQLAlchemy（异步）
- 数据库：MySQL 8.x


本模块为成员D负责的**商家后台功能模块**，包括：


- 商品管理
- 商家订单管理
- 售后审核
- 营收统计


本模块与成员E管理员后台共用同一个项目和数据库。

# 四、数据库配置


## 1. 数据库说明


本项目与成员E管理员后台共用数据库：

```
e_shop_admin
```


不会创建新的数据库。


成员D新增数据表：


```
product        商品表

order          商家订单表

after_sale     商家售后表
```


数据库整体结构：


```
e_shop_admin

│
├── admin              管理员表
├── user               用户表
├── category           类目表
├── brand              品牌表
├── product            商品表（成员D）
├── order              订单表（成员D）
├── after_sale         售后表（成员D）
└── operation_log      操作日志表
```


---

## 2. 执行数据库脚本


启动 MySQL 后执行：


```
backend/sql/init.sql
```


脚本会创建：


- 商品表 product
- 订单表 order
- 售后表 after_sale


并插入测试数据。


---

## 3. 修改数据库连接


打开：


```
backend/config/db_conf.py
```


修改：


```python
ASYNC_DATABASE_URL = "mysql+aiomysql://用户名:密码@localhost:3306/e_shop_admin?charset=utf8mb4"
```


例如：


```python
ASYNC_DATABASE_URL = "mysql+aiomysql://root:123456@localhost:3306/e_shop_admin?charset=utf8mb4"
```


注意：

- 用户名需要替换成本机 MySQL 用户
- 密码需要替换成本机 MySQL 密码
- 数据库名称保持 e_shop_admin

# 五、后端运行方式


## 1. 进入后端目录


```bash
cd backend
```


---

## 2. 创建虚拟环境


首次运行需要：


```bash
python -m venv .venv
```


Windows 激活：


```bash
.venv\Scripts\activate
```


---

## 3. 安装依赖


```bash
pip install -r requirements.txt
```


如果项目已经存在 requirements.txt：

请将成员D新增依赖合并进去。


新增依赖包括：


```
fastapi
uvicorn
sqlalchemy
aiomysql
pydantic
python-multipart
```


---

## 4. 启动后端服务


```bash
uvicorn main:app --reload --port 8000
```


启动成功后访问：


```
http://localhost:8000/docs
```


可以查看 FastAPI 接口文档。

# 十、合并注意事项


1. 成员D模块不会创建新的数据库。

2. 所有模块统一使用：

```
e_shop_admin
```


3. 前端需要保留统一路由：

```
Layout.vue

├── Dashboard

├── Product

├── Order

├── AfterSale

└── Statistics
```


4. 后端 main.py 需要统一注册路由：

```python
product.router

order.router

after_sale.router

statistics.router
```


5. requirements.txt 需要合并所有成员依赖。

# 十一、常见问题


## 1. 后端连接数据库失败


检查：

- MySQL 是否启动
- 用户名密码是否正确
- 数据库 e_shop_admin 是否存在


---

## 2. 前端无法访问接口


检查：

- 后端是否运行在 8000 端口
- vite.config.js 是否配置代理


---

## 3. 页面无法跳转


检查：

```
frontend/src/router/index.js
```


是否注册：

```
Dashboard

Product

Order

AfterSale

Statistics
```
