# 项目运行方式

> 项目：`E`（电商平台 - 管理员后台系统）
> 前端：Vue 3 + Vite + Element Plus ｜ 后端：FastAPI + SQLAlchemy（异步）+ MySQL

---

## 一、环境要求

| 软件 | 版本要求 | 说明 |
|---|---|---|
| Python | 3.10+（推荐 3.12/3.13） | 后端运行环境 |
| Node.js | 18+（推荐 20/22） | 前端构建环境，自带 npm |
| MySQL | 8.x | 数据库 |

---

## 二、数据库准备（两种方式任选其一）

### 方式一：手动执行 SQL 脚本（推荐）

1. 启动本地 MySQL 服务
2. 用 Navicat / DataGrip / mysql 命令行打开 `E/backend/sql/init.sql`
3. 直接执行（脚本会自动建库 `e_shop_admin`、建 7 张表、写入演示数据，可重复执行）

### 方式二：后端自动建表

什么都不用做，直接启动后端即可：
- 表不存在时自动创建
- 自动创建默认管理员 `admin / 123456`
- 但没有演示数据（用户、类目、品牌、订单、售后单为空）

> 两种方式都执行也没问题（`CREATE IF NOT EXISTS` + `INSERT IGNORE` 幂等设计）。

## 三、后端启动

```bash
# 1. 进入后端目录
cd E/backend

# 2. 创建虚拟环境（首次）
python -m venv .venv

# 3. 激活虚拟环境
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt
# 国内镜像加速（可选）：
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 5. 启动服务
uvicorn main:app --reload --port 8000
```

**启动前检查：** 打开 `E/backend/config/db_conf.py`，确认数据库连接地址与本地 MySQL 一致：

```python
ASYNC_DATABASE_URL = "mysql+aiomysql://root:123456@localhost:3306/e_shop_admin?charset=utf8mb4"
#                              └用户名┘└密码┘                  └库名┘
```

启动成功后：
- 控制台输出 `已创建默认管理员账号: admin / 123456`（首次）和 `[定时任务] 已启动，每 30 秒扫描一次超时售后单和到期封禁用户`
- 接口文档：http://localhost:8000/docs
- 两个定时任务已随服务启动：售后超时自动介入、封禁到期自动解封（各每 30 秒扫描一次）

## 四、前端启动

```bash
# 1. 进入前端目录
cd E/frontend

# 2. 安装依赖（首次）
npm install
# 国内镜像加速（可选）：
npm config set registry https://registry.npmmirror.com
npm install

# 3. 启动开发服务器
npm run dev
```

浏览器访问：**http://localhost:5173**

> 开发环境下 Vite 已配置代理：前端所有 `/api` 请求自动转发到 `http://localhost:8000`，无需处理跨域。

## 六、常见问题

### 1. 后端启动报连接数据库失败

- 确认 MySQL 服务已启动
- 确认 `config/db_conf.py` 中用户名/密码正确
- 确认 3306 端口未被占用或被防火墙拦截

### 2. `pip install` 报 aiomysql 安装失败

- 确认 Python 版本 ≥ 3.10
- 尝试清华镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 3. 前端 `npm install` 很慢或失败

- 切换国内镜像：`npm config set registry https://registry.npmmirror.com`
- 删除 `node_modules` 和 `package-lock.json` 后重试

### 4. 登录提示「用户名或密码错误」

- 如果是手动执行的 init.sql，密码为 `123456`（脚本中已内置加密结果）
- 如果是后端自动创建的账号，同样是 `admin / 123456`
- 可删除 `admin` 表数据后重启后端自动重建

### 5. 端口被占用

- 后端 8000 被占用：`uvicorn main:app --reload --port 8001`（同时修改 `frontend/vite.config.js` 中的代理 target）
- 前端 5173 被占用：Vite 会自动换端口，按控制台提示访问

### 6. 售后单没有自动介入

- 确认后端控制台有 `[售后自动介入任务] 已启动` 日志
- 自动介入仅针对 `status=0` 且 `deadline` 已过期的售后单
- 等待 30 秒后在前端「售后介入」页点击刷新查看
